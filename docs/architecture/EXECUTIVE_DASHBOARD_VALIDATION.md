# Executive Dashboard Validation Checklist

Use this checklist before launching or materially changing the Executive Dashboard. Do not mark a section complete until the dashboard values have been compared against the relevant source systems or accepted reconciliation records.

## Commerce

- [ ] Orders match source.
- [ ] Sales match source.
- [ ] Revenue matches source.
- [ ] AOV matches source.
- [ ] Products and brands match source.

## Attribution

- [ ] Affiliate conversions match source.
- [ ] Affiliate commission matches source.
- [ ] Source/campaign attribution matches source.

## Financial

- [ ] PayPal payments match.
- [ ] Refunds match.
- [ ] Partial refunds match.
- [ ] Chargebacks match.
- [ ] Chargeback fees match.
- [ ] Processing fees match.
- [ ] Reversals match.
- [ ] NMI snapshot totals match.
- [ ] NMI configured fee model matches contract.

## Profit

- [ ] Operational Profit formula verified.
- [ ] No duplicate deduction.
- [ ] Missing cost behavior verified.
- [ ] Snapshot Mode verified.
- [ ] Stale-source behavior verified.
- [ ] Reliable Through verified.
- [ ] Incomplete mapping behavior verified.

## Reconciliation

- [ ] Calculated amount preserved.
- [ ] Statement amount preserved.
- [ ] Variance calculated.
- [ ] Adjustment preserved.
- [ ] Closed period behavior verified.

## UI

- [ ] Loading state.
- [ ] Empty state.
- [ ] Partial data state.
- [ ] API failure state.
- [ ] Mobile layout.
- [ ] Accessibility.
- [ ] Filters.
- [ ] Navigation.
- [ ] Timestamps and timezone.
